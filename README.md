# Diffusion MRI Framework for Characterizing Neuropathology in Psychotic Disorders
---

## Overview

This repository contains the complete analysis code for the manuscript *"Diffusion Modeling for Characterizing Neuropathology in Psychotic Disorders: A Machine Learning Study"*. The study develops an integrated multi-compartment diffusion MRI framework that combines Intravoxel Incoherent Motion (IVIM), Free Water Imaging (FWI), and Diffusion Kurtosis Imaging (DKI) to model perfusion, extracellular neuroinflammation/edema, and tissue microstructural complexity in psychotic spectrum disorders.

The framework provides quantitative in-vivo microstructural characterization across 68 cortical parcellations (6 metrics each = 413 features) and evaluates machine learning classification pipelines for two primary tasks:
1. **Patient vs Control** — evaluating cohort-level microstructural separability between psychotic spectrum patients and healthy controls
2. **SCZ vs Non-SCZ** — evaluating biological subtype differentiation between schizophrenia spectrum and non-schizophrenia psychosis
3. **Model Component Ablation** — systematically evaluating the incremental value of multi-compartment integration compared to individual diffusion sub-models (DTI-only, DKI-only, DTI+DKI, IVIM-only, FWI-only, IVIM+FWI)

> **Clinical Scope Note:** The framework is designed for downstream objective microstructural stratification and mechanistic profiling rather than unguided population screening or direct treatment selection.

### Data

Diffusion-weighted imaging data was acquired from **1,267 participants** across two Human Connectome Project cohorts:
- **Healthy controls** (n = 1,094) from the **HCP Young Adult (HCP-YA)** cohort
- **Psychotic spectrum patients** (n = 173) from the **HCP Early Psychosis (HCP-EP)** cohort, including 83 with schizophrenia, 20 with schizoaffective disorder, and 70 with non-schizophrenia psychosis

Regional diffusion metrics were generated by fitting the **integrated IVIM-FWI-DKI (tricompartmental) model** using the DMIPY toolbox on multi-shell diffusion imaging data. This model simultaneously estimates:
- **Perfusion fraction (PF / fb)** via Intravoxel Incoherent Motion (IVIM)
- **Extracellular free-water fraction (FW / fw)** via Free Water Imaging (FWI)
- **Tissue microstructure and complexity (FA, MD, MK, KFA)** via Diffusion Tensor Imaging and Diffusion Kurtosis Imaging (DKI)

Metrics were extracted from 68 cortical parcellations (Desikan-Killiany atlas), yielding 413 features per participant. Place the data file at `data/finaldata.csv`.

## Pipeline Architecture

### Data Flow

```
01_noise_testing.ipynb ──────┐   # Rician noise sensitivity analysis
02_bias_testing.ipynb ───────┤   # Model-fitting sweep + noise bias viz
                             │
finaldata.csv ◄──────────────┘   (validation notebooks are self-contained)
    |
    v
03_data_preparation.ipynb
  - Imputation (median)
  - Diagnosis mapping
  - ComBat harmonization
  - Saves: data/*.pkl
    |
    v
04_pca_confound_analysis.ipynb     05_statistical_feature_analysis.ipynb
  - PCA on harmonized features     - KS tests per feature
  - Confound stratification        - Mann-Whitney U tests
  - Scree plot                     - Cohen's d effect sizes
    |                                 |
    +───────────────┬─────────────────+
                    |
                    v
06_patient_vs_control_classification.ipynb
07_scz_vs_non_scz_classification.ipynb
08_harmonization_robustness.ipynb
09_model_ablation_analysis.ipynb
  - Site-stratified 5-fold CV
  - Within-fold nested feature selection (top 20 by AUC)
  - Neural Network (64->32->16, L2 reg, Dropout) + Random Forest baseline
  - Sub-model ablation: DTI, DKI, DTI+DKI, IVIM, FWI, IVIM+FWI vs Full
  - Bootstrap confidence intervals (2,000 resamples)
  - All evaluation figures and tables
```

### Key Methodological Protections

1. **Nested feature selection**: Feature ranking and top-K selection recomputed independently within each training fold to eliminate data leakage.
2. **Site-stratified CV**: Each fold preserves site proportions to prevent scanner-driven splits.
3. **ComBat harmonization**: Removes additive/multiplicative site effects while preserving biological variance.
4. **Leave-One-Site-Out**: Cross-scanner generalizability verified by training on N-1 sites and testing on held-out sites.
5. **Component Ablation**: Rigorous statistical evaluation comparing the full tricompartmental model to constituent sub-models.
6. **Bootstrap CIs**: 95% confidence intervals via 2,000-fold bootstrap resampling.
7. **Calibration assessment**: Brier score + Expected Calibration Error (ECE) quantify probability reliability.
