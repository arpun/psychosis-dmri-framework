# Diffusion MRI Framework for Characterizing Neuropathology in Psychotic Disorders
---

## Overview

This repository contains the complete analysis code for the manuscript *"Diffusion Modeling for Characterizing Neuropathology in Psychotic Disorders: A Machine Learning Study"*. The study develops an integrated multi-compartment diffusion MRI framework that combines Intravoxel Incoherent Motion (IVIM), Free Water Imaging (FWI), and Diffusion Kurtosis Imaging (DKI) to simultaneously model perfusion, extracellular inflammation, and tissue complexity in psychotic spectrum disorders.

The pipeline uses microstructural features from 68 cortical parcellations (6 metrics each = 408 features) to train neural network classifiers for two tasks:
1. **Patient vs Control** — distinguishing psychotic spectrum patients from healthy controls
2. **SCZ vs Non-SCZ** — distinguishing schizophrenia spectrum from non-schizophrenia psychosis

### Data

The dataset (`data/finaldata.csv`) contains diffusion MRI metrics from 1,267 participants:
- **1,094 healthy controls** (HCP-YA cohort)
- **173 patients** with psychotic spectrum disorders (HCP-EP cohort), including:
  - 83 schizophrenia
  - 20 schizoaffective disorder
  - 70 non-schizophrenia psychosis

Diffusion-weighted imaging data was acquired from **1,267 participants** across two Human Connectome Project cohorts:
- **Healthy controls** (n = 1,094) from the **HCP Young Adult (HCP-YA)** cohort
- **Psychotic spectrum patients** (n = 173) from the **HCP Early Psychosis (HCP-EP)** cohort, including 83 with schizophrenia, 20 with schizoaffective disorder, and 70 with non-schizophrenia psychosis

Regional diffusion metrics were generated by fitting the **integrated IVIM-FWI-DKI (tricompartmental) model** using the DMIPY toolbox on multi-shell diffusion imaging data. This model simultaneously estimates:
- **Perfusion fraction (fb)** via Intravoxel Incoherent Motion (IVIM)
- **Extracellular free-water fraction (fw)** via Free Water Imaging (FWI)
- **Tissue microstructure and complexity (FA, MD, MK, KFA)** via Diffusion Tensor Imaging and Diffusion Kurtosis Imaging (DKI)

Metrics were extracted from 68 cortical parcellations (Desikan-Killiany atlas), yielding 408 features (6 metrics × 68 regions) per participant. See the manuscript (Sec. 3) for complete methodological details.

Place the data file at `data/finaldata.csv`.

### Neural Network Architecture

**Patient vs Control:**
- Input: 20 features (top AUC per fold)
- Hidden: 64 -> 32 -> 16 neurons (geometric power-of-2 decay)
- L2 regularization on all hidden layers
- Dropout (0.4) before output
- Output: 1 neuron (sigmoid)
- Loss: Binary cross-entropy with class weighting (balanced)

**SCZ vs Non-SCZ:**
- Input: 20 features (top AUC per fold)
- Hidden: 64 -> 32 neurons with Dropout (0.3, 0.2)
- Output: 1 neuron (sigmoid)

### Key Methodological Protections

1. **Nested feature selection**: Feature ranking and top-K selection recomputed independently within each training fold
2. **Site-stratified CV**: Each fold preserves site proportions to prevent scanner-driven splits
3. **ComBat harmonization**: Removes additive/multiplicative site effects while preserving biological variance
4. **Leave-One-Site-Out**: Cross-scanner generalizability verified by training on N-1 sites
5. **Bootstrap CIs**: 95% confidence intervals via 2000-fold bootstrap resampling
6. **Calibration assessment**: Brier score + Expected Calibration Error (ECE) quantify probability reliability
